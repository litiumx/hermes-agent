## 📋 Описание

Это ТРЕТЬЯ часть про Hermes Agent. Первые две — установка с нуля и полная настройка. Здесь — только то, что изменилось за месяц, по вашим же комментариям. Никакого пересказа базы.

За этот месяц у агента появился «судья»: отдельная проверка, которая после каждого хода требует ДОКАЗАТЕЛЬСТВО, что задача правда закрыта, и не принимает слово «готово» на веру. Это прямое лечение проблемы из первой части — агент, который рапортует «сделал», когда форма не отправилась. А сверх этого — то, что меняет саму идею работы с агентом: теперь он САМ создает себе навыки и гоняет пачку помощников в фоне, пока вы заняты своим. Разбираю четыре большие темы — четыре прямых ответа, с числами, именами и конфигами. А в самом конце — отдельный блок «приёмы продвинутых».

## 1️⃣ Хук: агент умеет ВРАТЬ? Теперь у него есть судья (0:00)

**Ключевая проблема Hermes Agent:** агент часто говорит «сделал», когда на самом деле задача не выполнена. Форма не отправилась, но агент рапортует успех.

**Решение:** теперь у агента есть «судья» — отдельная проверка, которая после каждого хода:
- Требует ДОКАЗАТЕЛЬСТВО, что задача реально закрыта
- Не принимает слово «готово» на веру
- Проверяет результат инструментальными средствами

**Дополнительно:** агент теперь САМ создает себе навыки и может гонять пачку помощников в фоне, пока пользователь занят своим делом.

## 3️⃣ Тема 1/4 · ПАМЯТЬ: стек слоями (2:40)

### Архитектура памяти в Hermes Agent 3.0

| Слой | Технология | Назначение |
|------|-----------|------------|
| 1. Markdown (MD) | Файловая память | Исходные данные, SOUL.md, AGENTS.md |
| 2. Векторная база | Векторное хранилище | Семантический поиск по фактам |
| 3. Zep | Сторонний сервис | Долговременная контекстная память |
| 4. Reflexion | Самоанализ | Рефлексия над собственными действиями |

### Новые возможности памяти:
- **Семантический поиск** — агент находит релевантные факты по смыслу, а не по ключевым словам
- **Карта памяти `/journey`** — визуализация того, что агент помнит и как связывает факты
- **Obsidian** — интеграция с персональной базой знаний

### 🚀 Агент САМ куёт навыки (внутри темы 1)

- **Команда `/learn`** — агент обучается новому навыку из описания
- **«Победа → навык»** — если агент успешно решил задачу, он может превратить это в новый навык
- **Двусторонняя вики по Карпати** — агент читает и пишет в свою базу знаний

## 4️⃣ Тема 2/4 · ДЕШЁВЫЙ УМНЫЙ АГЕНТ (9:40)

### Экономика умного агента

| Компонент | Стоимость |
|-----------|-----------|
| **GLM 5.2** (китайская open-source LLM) | **$18/мес** вместо $90 у Claude |
| OAuth-квота Claude | Бесплатно для разработчиков |
| Grok 4.5 | $30/мес (xAI) |
| Kimi K3 | ~$10-15/мес |

### Почему GLM 5.2 — главный сдвиг 2026

- Китайская флагманская модель от Zhipu AI
- Ставится на свой сервер, работает без интернета
- По кодингу практически не уступает Claude Opus 4.8
- Не требует зарубежных подписок
- **Идеально для РФ:** нет санкционных рисков

### 🚀 Пачка агентов в фоне (внутри темы 2)

- **Fork-субагенты** — запуск копий агента для параллельных задач
- **Панель управления** — визуальный мониторинг всех агентов
- **«Модель-под-скилл»** — автоматический подбор модели для конкретной задачи
- **Микс моделей в оркестрации** — разные LLM для разных этапов

## 5️⃣ Тема 3/4 · РОУТИНГ + ОБЛАКО (17:30)

### Архитектура роутинга

```
┌─────────────────────────────────────┐
│        Hermes Core (~/.hermes)       │
│          ├── main модель             │
│          ├── auxiliary модели        │
│          └── OpenRouter роутеры       │
└─────────────────────────────────────┘
```

### Роутеры OpenRouter
- Автоматический выбор модели под задачу
- fallback-цепочки при недоступности
- Экономия: дешёвые модели для простых задач

### Облачная инфраструктура
- Одна система в папке `~/.hermes`
- Облачный хостинг от **$5-6/мес**
- Доступ из любого места

## 6️⃣ Тема 4/4 · КЛЕТКА ДЛЯ АГЕНТА (22:35)

### Защита агента: 4 вектора обхода денлиста

| Вектор атаки | Описание | Защита |
|-------------|----------|--------|
| Prompt injection | «Взлом» бота через сообщение | Guardrails на входе |
| Escape терминала | Выход за пределы разрешённых команд | Денлист + «клетка снаружи» |
| Утечка данных | Извлечение приватной информации | PII скруббер, локальные модели |
| Обход авторизации | Доступ без прав | SECURITY.md, ролевая модель |

### Результаты защиты
- **−84% запросов** отфильтровываются до попадания к модели
- **SECURITY.md** — формальная модель безопасности
- **«Судья»** — проверяет доказательства выполнения
